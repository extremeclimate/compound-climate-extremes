# Compound Climate Extremes

This repository contains selected code associated with a study of compound climate extremes.

## Code and data availability

A subset of the code used in this study is currently available in this repository.

The complete code and processed data supporting the study will be made available during the peer-review process to facilitate evaluation and reproducibility.

If access to additional code or data is required before the full materials are made available for peer review, requests may be directed to the journal editorial office or to the corresponding author through the journal's submission system.

Following acceptance, the complete code and processed data required to reproduce the analyses and results will be made publicly available in this repository.

## Repository contents

The materials currently available include selected scripts for data processing, analysis and visualization. Additional code, processed data and supporting documentation will be added as the manuscript progresses through peer review.
